# 새 글 올리는 법

가장 쉬운 방법: 클로드에게 **"이런 내용으로 글 하나 써서 올려줘"** 라고 말하면 됩니다.
아래는 직접 하실 때의 순서입니다.

1. `_TEMPLATE.html` 을 복사해서 새 이름으로 저장합니다.
   파일 이름은 영문 소문자와 하이픈만: `omega3-ratio.html`, `balance-test-guide.html`
2. 파일 안에서 `[ ]` 로 표시된 곳만 바꿉니다 (제목, 요약, 키워드, 날짜, 파일이름).
3. `index.html` (이 폴더의 목록 페이지) 의 `<ul class="posts">` 맨 위에 카드 하나를 추가합니다.
   바로 아래 있는 카드를 복사해서 제목·요약·날짜·링크만 바꾸면 됩니다.
4. 사이트 맨 위 폴더의 `sitemap.xml` 에 새 글 주소를 한 줄 추가합니다.
5. 저장하고 깃헙에 올리면 20초쯤 뒤 사이트에 뜹니다.

## 검색이 잘 되는 글의 조건

- 제목에 사람들이 실제로 검색하는 말을 넣습니다. "진지노 오메가3 하루 섭취량" 처럼.
- 요약(description) 은 검색 결과에 그대로 보입니다. 클릭하고 싶게 씁니다.
- 소제목(h2) 을 질문형으로 쓰면 AI 검색이 잘 가져갑니다. "왜 검사부터 하나요?"
- 사진에는 반드시 alt 설명을 씁니다.
- 건강 관련 표현은 식약처 인정 범위 안에서만: "도움을 줄 수 있음". 치료·예방·완치 표현 금지.
