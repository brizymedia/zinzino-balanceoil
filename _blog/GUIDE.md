# 진지노 블로그 루틴 작업 설명서

www.zinzinoshop.co.kr 의 **진지노 이야기** 블로그에 매일 글을 올리는 루틴이 따르는 규칙이다.
사람이 고칠 때도 이 문서를 먼저 고친다.

- 하루 분량: **홈페이지 글 5개 + 네이버 블로그용 원고 2개**.
- 올리는 곳: 글 5개는 전부 `www.zinzinoshop.co.kr/blog/` 한 곳. 사업·파트너 이야기도 여기 쓰고 zinzino.asia 도구로 링크를 건다.
  블로그를 두 사이트로 쪼개면 둘 다 약해진다. 검색 힘은 한곳에 모은다.
- 읽는 사람 둘:
  1. **오메가3를 고르는 사람** — 영양제를 먹고 있는데 효과가 있는지 모르겠는 사람. (주된 독자)
  2. **시간이 없는 직장인** — 부업은 알아보고 싶은데, 사업설명회에 나오라는 말에 지친 사람.
     본업이 있고 일정이 안 맞는다. 저녁마다 불려 나가는 일은 못 한다. **이 사람이 우리 사람이다.**
- 원칙: **틀린 정보 한 줄이 글 한 편보다 해롭다.** 건강기능식품은 표현 하나로 행정처분을 받는다.
  확인 못 한 것은 쓰지 않는다.

## 1. 전략 — 왜 제품이 먼저인가

2026-09-12 네이버 데이터랩으로 실제 검색량을 쟀다. 결과가 전략을 정했다.

| 키워드 묶음 | 검색량 | 판단 |
|---|---|---|
| 진지노 밸런스오일 · 진지노 오일 · 진지노 오메가3 | 2026-08 최고점, 지금도 살아 있음 | **여기에 힘을 쏟는다** |
| 진지노 · 진지노코리아 | 7월 론칭 때 정점, 지금은 절반 | 브랜드 검색은 이미 본사가 가져간다 |
| 진지노 사업 · 부업 · 창업 · 가입 | **데이터랩이 수치를 안 줄 만큼 적음** | 글은 쓰되 개수를 적게 |
| 오메가3 검사 · 밸런스테스트 | **수치 없음** | 단독 주제로 쓰지 않는다 |

그래서 **하루 5개 중 3개는 제품·건강, 1개는 파트너·사업, 1개는 도구·자동화**로 짠다(7장).

다만 「진지노 ○○」만 노리면 본사와 오픈마켓을 못 이긴다.
**브랜드를 모르는 사람이 치는 말**을 같이 잡는다 — `오메가3 추천`, `액상 오메가3`, `오메가3 비린내`,
`중성지방 낮추는 법`, `눈 건조 영양제`, `오메가3 언제 먹어야`. 이 글에서 진지노로 데려온다.

## 2. 우리는 누구인가 — 진지노 온라인 그룹

우리 팀 이름은 **진지노 온라인 그룹**이다. 이름에 전략이 다 들어 있다.

**우리가 푸는 문제**

네트워크 마케팅을 알아보다 그만두는 가장 흔한 이유는 제품도 보상도 아니다. **오라는 데가 너무 많아서**다.
사업설명회, 팀 미팅, 센터 방문. 본업이 있는 사람은 일정을 못 맞춘다. 몇 번 빠지면 눈치가 보이고, 그러다 그만둔다.

우리는 그걸 안 시킨다.

| 보통의 방식 | 진지노 온라인 그룹 |
|---|---|
| 센터로 나오세요 | **온라인 사업설명회** — 있는 자리에서 듣는다 |
| 사람을 데리고 오세요 | **링크를 보낸다** — 자료실 주소 하나면 끝 |
| 무슨 말을 할지 배우세요 | **15단계 퍼널이 문구를 준다** — 복사해서 카톡·문자 |
| 수당은 나중에 배우세요 | **계산기에 숫자를 넣어 본다** — 지금 바로 |
| 자료는 받아 가세요 | **전부 링크와 이미지** — 인쇄물도 내려받아 쓴다 |

**글에 쓰는 법**
- 다른 팀을 깎아내리지 않는다. 「모여야 힘이 나는 사람도 있습니다」를 인정하고, **선택지를 하나 더 주는** 자리로 쓴다.
- 「집에서 폰으로만 해도 됩니다」까지만. **「안 만나도 된다」가 아니라 「안 나가도 시작할 수 있다」**다.
- 온라인 사업설명회의 요일·시간·참여 방법은 **형님께 확인한 뒤에만** 구체적으로 쓴다.
  확인 전에는 「온라인으로 듣습니다」까지만 쓰고, 신청은 상담으로 보낸다.

## 3. 우리만 말할 수 있는 것 — 파트너 도구

다른 파트너 블로그는 전부 제품과 보상플랜만 말한다. 우리는 **도구를 만들어 쓴다.** 이게 유일한 차별점이다.
사업 글과 도구 글에는 반드시 이 축을 넣는다.

| 도구 | 주소 | 무엇을 해결하나 |
|---|---|---|
| 지인 명단 해바라기 · 15단계 퍼널 | `https://zinzino.asia/funnel.html` | 이름을 넣으면 그 사람에게 보낼 문자·카톡 문구가 15단계로 나온다. 주소록에서 바로 불러온다 |
| 내 예상 수익 계산기 | `https://zinzino.asia/calculator.html` | 직추천·후원 수를 넣으면 예상 직급과 12개월 수익 흐름이 표와 그래프로 |
| 쉬운 보상플랜 로드맵 | `https://zinzino.asia/plan.html` | 보상플랜을 중학생 눈높이로 |
| 사업 자료실 | `https://zinzino.asia/materials.html` | 계산기·보상플랜·슬라이드·리플렛·홍보 전단을 카톡으로 바로 공유 |
| 홍보 전단 (A4 양면) | `https://zinzino.asia/leaflet.html` | 인쇄용 PDF와 이미지. 담당자·연락처 칸은 비어 있음 |
| 혈관 나이 자가진단 | `https://www.zinzinoshop.co.kr/blood-age.html` | 10문항 1분. 고객에게 먼저 보낼 미끼 |

**쓰는 법**
- 「AI가 대신 영업해 줍니다」처럼 부풀리지 않는다. **도구가 하는 일만** 그대로 쓴다.
- 도구 글은 링크를 걸고 「직접 눌러 보세요」로 끝낸다. 읽는 사람이 확인할 수 있는 것이 우리 신뢰다.
- 없는 기능을 쓰지 않는다. 위 표에 적힌 것이 전부다.

## 4. 실제 사례 — 세 가지만 쓴다

「사례」는 아래 셋뿐이다. 이 밖의 사례는 만들지 않는다.

**① 우리 도구 사례 (가장 안전하고 가장 강하다)**
- 「지인 명단을 넣으면 보낼 말이 나오는 도구를 만들었습니다」처럼 **우리가 만든 것**을 보여준다.
- 화면 갈무리 + 링크. 읽는 사람이 직접 눌러 확인할 수 있어야 한다.
- 법적 위험이 없고, 다른 파트너 글에는 없는 내용이다.

**② 검사 전후 수치 (회사 자료)**
- 180만 건 검사에서 시작 시 정상 범위 3%, 120일 뒤 95%가 약 3:1 — 이 수치는 쓸 수 있다.
- **반드시 「진지노 회사 자료 기준」과 「개인차가 있을 수 있습니다」를 같은 화면에 붙인다.**
- 개인을 특정하지 않는다. 이름·나이·사진을 붙이지 않는다.

**③ 형님(김효민)이 직접 겪은 일**
- 형님이 주신 내용만 쓴다. 내가 지어내지 않는다.
- **쓸 수 있는 것**: 검사 수치가 이렇게 바뀌었다 / 먹는 방법을 이렇게 바꿨다 / 사업하며 겪은 일.
- **쓸 수 없는 것**: 무엇이 나았다 · 좋아졌다 · 병이 사라졌다 — 질병 개선을 암시하면 체험기 광고가 된다.
- 자료가 없으면 그 글에는 ③을 넣지 않는다. 형님께 「이런 사례가 있으면 달라」고 보고에 적는다.

## 5. 절대 쓰지 않는 것

### 건강 — 식품표시광고법

- **질병의 예방·치료·개선을 암시하는 말.** 「혈압이 내려간다」 「치매 예방」 「관절에 좋다」 「염증을 잡는다」
  「면역력을 높인다」 「피가 맑아진다」 — 전부 금지.
- 식약처가 인정한 기능성은 **이 네 가지 문장 그대로**만 쓴다.
  - 혈중 중성지질 개선에 도움을 줄 수 있음
  - 혈행 개선에 도움을 줄 수 있음
  - 건조한 눈을 개선하여 눈 건강에 도움을 줄 수 있음
  - 기억력 개선에 도움을 줄 수 있음
- 「~에 좋습니다」로 줄여 쓰지 않는다. 「도움을 줄 수 있습니다」까지 붙인다.
- 체험기·후기·고객 발언·「먹어 봤더니」 — 4장 ③ 범위 밖은 전부 금지.
- 의약품과 견주지 않는다. 「약 대신」 「약보다」 금지.
- 글 끝에 **「본 제품은 질병의 예방 및 치료를 위한 의약품이 아닙니다.」**를 반드시 넣는다(생성기가 자동으로 붙인다).

### 사업 — 방문판매법

- **소득 보장·단정 금지.** 「월 ○○만원 벌 수 있습니다」 「3개월이면 ○○」 — 금지.
  계산기는 「예상·시뮬레이션」임을 같이 쓴다.
- 다이아몬드 이상은 **소수가 도달하는 직급**이라고 정직하게 쓴다.
- 「쉽게」 「누구나」 「자동으로 돈이」 — 쓰지 않는다.
- 사업 이야기가 들어간 글에는 **「수입은 개인의 활동에 따라 다르며 보장되지 않습니다.」**를 넣는다.

### 그 밖에

- **가격·단가를 쓰지 않는다.** 구성과 가격은 상담에서 안내한다(사이트 정책). 오픈마켓 가격도 옮기지 않는다.
- **「미국 나스닥」이라 쓰지 않는다.** 나스닥 스톡홀름 퍼스트 노스 프리미어다.
- 다른 회사·다른 제품을 이름 들어 비방하지 않는다. 비교는 「일반적인 캡슐형 오메가3」처럼 일반화한다.
- 「1위」 「최고」 「100%」 「무조건」 — 근거를 댈 수 있는 것만(모멘텀 랭킹 1위는 Business For Home 출처를 단다).
- 남의 사진·기사 본문을 가져오지 않는다. KBS·유튜브는 **인용 표시와 출처**를 단 범위에서만.
- 사람 얼굴이 크게 나온 사진, AI로 만든 제품 그림.

## 6. 글 형식 (JSON)

`_blog/posts/<날짜>-<slug>.json`

| 칸 | 규칙 |
|---|---|
| `slug` | 영소문자·숫자·`-`, 60자 이하. 예: `omega3-liquid-vs-capsule` |
| `date` | 한국 날짜 `YYYY-MM-DD`. 파일 이름은 `<date>-<slug>.json` |
| `track` | `product` · `health` · `business` · `tool` 중 하나 (7장 배분) |
| `topic` | `keywords.json` 의 topic id. 같은 topic 은 한 번만 |
| `title` | 20~55자. 핵심 키워드를 통째로 앞쪽에 |
| `description` | 70~160자. 검색 결과에 그대로 보인다 |
| `keyword` | `{ "main": "핵심 키워드", "sub": ["보조", …] }` |
| `lead` | 100~450자. 첫 문장에 결론. 「~에 대해 알아보겠습니다」로 시작하지 않는다 |
| `points` | 3~5개. 본문을 안 읽어도 답이 되는 문장 |
| `sections` | 4~8개. `{ "h2": "1. …", "blocks": [ … ] }` |
| `faq` | 2~6개. `{ "q", "a" }`. 답에서 새 약속을 만들지 않는다 |
| `근거` | **3개 이상.** `{ "내용": 본문에 그대로 있는 구절, "출처": "facts.json" 또는 주소 }` |
| `cta` | `product` · `tool` · `business` 중 하나. 글 끝 행동 유도 블록을 고른다 |

`blocks`: `{ "p": … }` · `{ "ul": [..] }` · `{ "ol": [..] }` · `{ "table": { "head": [..], "rows": [[..]] } }` · `{ "tip": … }` · `{ "quote": { "text", "from" } }`

꾸밈은 둘뿐: `**굵게**`, `[링크 글자](/주소)`.

## 7. 하루 5개 배분

| 갈래 | 개수 | 내용 |
|---|---|---|
| `product` | 2 | 진지노 제품 자체 — 성분·먹는 법·비교·보관·검사 |
| `health` | 1 | 브랜드를 모르는 사람이 치는 말 — 오메가3 고르는 법, 중성지방, 눈 건조 |
| `business` | 1 | 사업·가입·보상플랜·법적 안전장치. **바쁜 직장인이 온라인으로 시작하는 길**을 축으로 |
| `tool` | 1 | 우리 도구와 자동화 — 3장 표의 도구들. 「안 나가고도 된다」를 도구로 증명한다 |

- 같은 날 같은 `topic` 두 번 금지. 같은 `main` 키워드 두 번 금지.
- `health` 글에도 마지막엔 진지노로 이어지는 문단을 둔다. 다만 **글의 8할은 진지노 없이도 쓸모 있어야** 한다.
- `business` 글은 반드시 3장의 도구 하나 이상을 링크한다. 「우리는 도구를 준다」가 모집의 축이다.

## 8. 좋은 글의 기준

- 합니다체, 짧은 문장, 쉬운 말. 전문용어는 처음 나올 때 풀어 쓴다.
- 첫 문단이 답이다. 빈 도입부를 쓰지 않는다.
- 표 1개 이상. 읽는 사람이 저장해 두고 쓸 수 있는 것.
- 내부 링크 2개 이상 — 관련 블로그 글, 그리고 `cta`에 맞는 도구·상담 주소.
- 핵심 키워드는 제목·설명·첫 문단·소제목 하나에 자연스럽게. 본문에서 12번 넘으면 검사기가 막는다.
- 분량 1,800자 아래는 막힌다. 2,500자쯤이 알맞다. 채우려고 늘리지 않는다.
- 같은 주제를 다시 쓸 때 문장을 돌려 쓰지 않는다. 기존 글과 30% 넘게 겹치면 검사기가 막는다.

## 9. 네이버 블로그용 원고 (하루 2개)

홈페이지 글을 그대로 네이버에 올리면 유사문서로 걸러 한쪽이 검색에서 빠진다.
같은 사실을 **다시 쓴 원고**를 따로 만든다. 발행은 사람이 한다.

- 대상: 그날 글 5개 중 **`product` 1개 + `business` 또는 `tool` 1개**.
- 파일: `_blog/naver/<원글과 똑같은 파일 이름>`.
- 원글과 25% 넘게 겹치면 검사기가 막는다. 도입·순서·문장을 새로 짠다.
- 원글에 없는 숫자는 쓰지 않는다.
- 표·링크 문법·`**굵게**`·`#` 소제목을 쓰지 않는다. 네이버 편집기에서 글자 그대로 보인다.
- 5장의 금지 목록이 그대로 적용된다.
- 태그 3~10개, `#` 없이.

```json
{
  "날짜": "2026-09-12",
  "제목": "12~40자 · 핵심 키워드를 넣되 홈페이지 제목과 다르게",
  "본문": [
    "문단은 2~4줄로 짧게. 문단 6개 이상, 전체 700~2500자.",
    "다음 문단…"
  ],
```

## 10. 하루 순서

1. 최신 main 에서 시작한다. `node scripts/blog-plan.mjs` 로 오늘 쓸 5개를 받는다.
2. 글마다 `_blog/facts.json` 을 읽고, **거기 있는 사실과 출처를 단 것만** 쓴다.
3. `_blog/posts/<날짜>-<slug>.json` 5개를 쓴다. `근거` 칸을 반드시 채운다.
4. 네이버 원고 2개를 `_blog/naver/` 에 쓴다.
5. `node scripts/blog-check.mjs --new <파일들>` 이 통과할 때까지 고친다.
   세 번 고쳐도 안 되면 그 글은 버린다. **검사기를 통과시키려고 억지 문장을 끼워 넣지 않는다.**
6. `node scripts/build-blog.mjs` 로 사이트를 만들고 커밋·푸시한다.
7. 끝에 보고한다.

```
오늘 올린 글 N개
1. [갈래] 제목 — 핵심 키워드
…
네이버 원고 2개: 제목 (https://www.zinzinoshop.co.kr/naver/ 에서 복사)
건너뛴 주제: 주제 — 이유
형님께 필요한 것: (사례·사진·확인이 필요한 사실. 없으면 "없음")
```
