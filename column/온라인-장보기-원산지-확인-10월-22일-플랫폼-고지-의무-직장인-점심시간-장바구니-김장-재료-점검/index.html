온라인 장보기 원산지 확인 — 10월 22일 플랫폼 고지 의무, 직장인 장바구니 점검

2026-10-22 · 진지노 밸런스 오일 플러스 · 읽는 시간 약 4분
온라인 장보기 원산지 확인원산지 표시제도 고지 의무오픈마켓 원산지 표시김장 재료 원산지

점심시간에 휴대폰으로 식품을 주문한다면 결제 전에 상품 정보의 원산지 칸을 한 번 열어 보는 것이 온라인 장보기 원산지 확인의 전부이자 시작입니다. 10월 22일부터는 오픈마켓·배달앱 같은 중개 플랫폼이 입점 판매자에게 원산지 표시 대상과 표시방법, 거짓 표시 제재를 알려야 합니다(농림축산식품부). 판매자 쪽 안내가 강화된 만큼 구매자는 무엇을 보고, 이상할 때 어디에 알리면 되는지 직장인 장바구니 기준으로 정리했습니다.

핵심만 먼저
  • 10월 22일부터 통신판매중개업자는 입점업체에 원산지 표시 대상 범위·표시방법과 거짓 표시 금지·제재를 알려야 하고, 알리지 않으면 과태료를 냅니다.
  • 결제 전 상품 정보의 원산지 칸, 옵션별 원산지, 세트 구성품별 원산지를 차례로 확인합니다.
  • 이번 발표는 국내 플랫폼과 입점업체 사이의 고지를 다룬 것이라, 해외 판매자에게 직접 사는 해외직구는 판매 페이지 정보를 따로 확인합니다.
  • 받은 물건의 원산지가 화면과 다르면 국립농산물품질관리원 부정유통 신고 1588-8112로 알릴 수 있습니다.

110월 22일부터 판매자 쪽에서 무엇이 달라졌나요?

10월 22일플랫폼의 원산지 표시제도 고지 의무 시행(농림축산식품부)
256개소추석 원산지 표시 위반 적발(국립농산물품질관리원)
273건추석 점검 위반 품목 건수

농림축산식품부는 원산지표시법 시행령·시행규칙 개정안이 10월 22일부터 시행된다고 밝혔습니다. 통신판매중개업자, 곧 여러 판매자가 입점하는 오픈마켓·배달앱 같은 플랫폼은 판매를 의뢰받은 때 입점업체에 원산지 표시 대상 농수산물·가공품의 범위와 표시방법, 거짓 표시 금지와 위반 시 제재를 알려야 합니다. 방법은 공지사항 상시 게시, 별도 안내 화면, 전자우편·문자 개별 안내 가운데 하나이고, 알리지 않으면 위반 횟수에 따라 과태료가 올라갑니다.

농식품부는 이번 개정으로 입점업체가 원산지 표시 의무와 제재를 정확히 알게 되어 위반을 예방하고 소비자의 알권리가 한층 보장될 것이라고 설명했습니다. 구매자에게 직접 새로 생긴 의무는 없지만, 화면의 원산지 정보를 읽는 습관이 있으면 이 변화를 그대로 활용할 수 있습니다.

2점심시간 5분, 결제 전에 어디를 보면 되나요?

  1. 상품 화면의 상품 정보 칸에서 원산지 항목을 찾습니다.
  2. 옵션을 고르는 상품이면 내가 고른 옵션의 원산지가 따로 적혀 있는지 봅니다.
  3. 선물 세트·꾸러미는 구성품마다 원산지가 적혀 있는지 확인합니다.
  4. 원산지가 비어 있거나 상세설명과 정보 칸이 다르면 판매자 문의로 먼저 물어봅니다.
  5. 결제한 뒤에는 상품 화면을 캡처해 주문 내역과 함께 둡니다.
주문을 자주 하는 직장인이라면 휴대폰 앨범에 '장보기 캡처' 폴더를 하나 만들어 두면 나중에 비교하기 편합니다. 다른 생활 점검표는 진지노샵 칼럼에 모아 두었습니다.

3해외직구로 식품을 살 때는 무엇이 다른가요?

이번 보도자료가 다루는 것은 국내 통신판매중개업자가 입점업체에 원산지 표시제도를 알리는 일입니다. 해외 판매자에게 직접 주문하는 해외직구가 이 고지 의무와 어떻게 연결되는지는 발표에 나와 있지 않으니, 직구 상품은 판매 페이지 정보를 스스로 꼼꼼히 확인하는 것이 안전합니다.

구매 방식이번 발표와의 관계구매자가 볼 것
국내 오픈마켓 입점 판매자플랫폼이 판매자에게 원산지 표시제도를 알려야 함(10.22~)상품 정보 칸의 원산지, 옵션·구성품별 표기
배달앱 음식점배달앱도 통신판매를 중개하는 플랫폼에 해당할 수 있음메뉴 설명의 원산지 안내
해외 판매자에게 직접 구매(해외직구)발표에서 다루지 않음판매 페이지의 원산지·제조국 정보, 판매자 정보
판매자 자사 홈페이지중개 플랫폼을 거치지 않음상품 페이지의 원산지 표기
영양제처럼 가공식품을 고를 때도 화면에 적힌 정보가 판단의 출발점입니다. 원산지·제조국·판매자 정보가 비어 있는 상품은 결제를 서두르지 않습니다.

4부모님 김장 재료를 대신 주문한다면?

국립농산물품질관리원은 9월 7일부터 23일까지 추석 성수품 원산지를 점검해 256개소를 적발했고, 위반 품목 273건 가운데 배추김치가 84건으로 가장 많았다고 10월 1일 밝혔습니다. 김장철에도 배추·고춧가루·마늘 등 소비가 많은 품목을 중심으로 점검하겠다고 했습니다.

  • 절임배추·고춧가루·마늘은 품목마다 원산지를 따로 확인하고 캡처합니다.
  • 나눠 담아 다시 포장한 고춧가루는 라벨과 상품 화면을 비교합니다(추석 점검에서 외국산 고춧가루를 소분·재포장해 국내산으로 표시한 사례가 적발됐습니다).
  • 부모님 댁으로 바로 배송시키면 도착 사진을 보내 달라고 부탁해 라벨을 확인합니다.

5받은 물건의 원산지가 화면과 다르면 어떻게 하나요?

국립농산물품질관리원 누리집 첫 화면에는 부정유통 신고 전화 1588-8112가 안내돼 있습니다. 퇴근 뒤 차분히 아래 순서로 정리하면 됩니다.

  1. 주문 화면 캡처와 받은 물건의 라벨 사진을 준비합니다.
  2. 주문 번호와 판매자 이름을 메모합니다.
  3. 판매자 문의나 플랫폼 고객센터에 사실을 알립니다.
  4. 원산지 거짓 표시가 의심되면 국립농산물품질관리원 부정유통 신고 1588-8112로 신고합니다.

자주 묻는 질문

10월 22일부터 구매자가 새로 해야 할 일이 있나요?

새 의무는 통신판매중개업자가 입점업체에 원산지 표시제도를 알리는 것입니다. 구매자에게 새로 생긴 의무는 없고, 결제 전에 상품 정보의 원산지를 확인하는 습관이면 충분합니다.

해외직구 식품도 이번 고지 의무가 적용되나요?

농림축산식품부 발표는 국내 통신판매중개업자와 입점업체 사이의 고지를 다룹니다. 해외직구와의 관계는 발표에 나오지 않으니 판매 페이지의 원산지·제조국·판매자 정보를 직접 확인합니다.

원산지가 의심되면 어디에 신고하나요?

국립농산물품질관리원 부정유통 신고 전화 1588-8112로 신고할 수 있습니다. 주문 화면 캡처와 라벨 사진을 함께 준비하면 설명이 쉽습니다.
